      Compte du jeu

      Le bot reprend d'abord la session enregistrée dans son Chrome. Le mot de passe ne sert que si cette session a expiré : enregistré ici, il n'est plus demandé dans la fenêtre du bot.

        Où est le mot de passe ?

        Dans captures/identifiants.json, sur ce PC seulement, chiffré par Windows pour ton compte Windows (même protection que les mots de passe de Chrome) : ouvert sur un autre PC, il est illisible. Il n'est jamais renvoyé à cette page ni écrit dans un journal. Effacer le mot de passe le supprime du fichier.

              Quand réagir

              Quand une attaque part vers un de tes châteaux, le jeu l'annonce avec une estimation du nombre de soldats (ton bailli la précise en approchant ; le bot décide dès l'apparition de l'attaque). À partir du nombre ci-dessous, tous les soldats du château attaqué (pas les engins) partent en soutien chez le membre de l'alliance en protection le plus proche, sur le même monde. Ils sont rappelés dès que l'attaque est passée. Pendant ce temps, les autres modules sont en pause sur ce monde seulement.

              Les types de soldats moins nombreux restent au château : pas de commandant pris pour quelques miettes. Chaque commandant emmène jusqu'à 10 types de soldats, les plus nombreux d'abord.

              Commandants

              Pour chaque monde, le commandant qui emmène en premier les soldats les plus nombreux (par exemple celui qui baisse le coût des envois de troupes). S'il reste des soldats, le bot complète avec d'autres commandants libres, d'abord ceux qu'aucun module n'utilise. Numéros comme dans le jeu ; laisse vide pour laisser le bot choisir.

              Porte de secours (rubis)

              Si l'attaque est vue trop tard, ou si les soldats n'ont pas pu partir, le bot peut ouvrir la porte du château : les soldats restés ne sont pas tués. L'ouverture est payée en rubis (450 lors de la capture) ; le bot refuse au-delà de 2000 rubis.

              Activer
              Aucune modification.

                Répartition des ressources entre les royaumes

                Toutes les 5 minutes, le bot lit les ressources de tous tes châteaux et envoie :

                • la ressource spéciale de chaque royaume (vert : fer, glacier : charbon, sables : huile, pics de feu : verre) vers les autres royaumes qui en manquent, dans l'ordre vert, glacier, sables, feu ;
                • le bois et la pierre des royaumes où le module tours tourne, quand ils y sont pleins, vers les royaumes où il ne tourne pas et qui en manquent.

                Pas de réserve gardée au départ : les tours et les fiefs remplissent au fur et à mesure. Les royaumes attaqués (module défense) sont laissés de côté pendant l'attaque.

                Accélérer les envois

                Sans accélération, un envoi met 2 h à arriver.
